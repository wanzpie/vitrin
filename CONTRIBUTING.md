# Contributing to Vitrin

1. Read `docs/AGENT.md`.
2. Read the relevant section of `docs/PRD.md` and `docs/PLAN.md`.
3. Branch from `main` using `feat/*`, `fix/*`, or `chore/*`.
4. Use Conventional Commits.
5. Add/update tests for changed business logic.
6. Never commit secrets or production credentials.
7. Payment, order, payout, risk-scoring, and IAM changes require human review.

See `docs/AGENT.md` for the complete rules.
